# Pet Simulator Game

## Overview

This is a simple command-line Pet Simulator game made while practicing Python.

The player creates a virtual pet and can feed it, play with it, and check its status.

## Features

- Create a pet
- Feed the pet
- Play with the pet
- Check pet happiness
- View pet status
- Exit option

## Concepts Practiced

- Classes and Objects
- Methods
- Encapsulation
- Functions
- Loops
- Conditional Statements
- User Input
