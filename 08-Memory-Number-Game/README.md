# Memory Number Game

## Overview

This project is a simple command-line Memory Number Game built using Python.

The program displays a list of random numbers for a few seconds. The player must remember the numbers and enter them in the correct order after they disappear.

---

## Features

* Random number generation
* Memory challenge
* Multiple rounds
* Play again option
* Beginner-friendly code

---

## Concepts Practiced

* Lists
* Loops
* Functions
* User Input
* Conditional Statements
* Random Module
* Time Module
