# Racing Car Game

## Overview

This is a simple command-line Racing Car game made while practicing Python.

The player races against the computer, and the first car to reach the finish line wins.

## Features

- Player vs Computer
- Random movement
- Race progress
- Winner detection

## Concepts Practiced

- Classes and Objects
- Functions
- Loops
- Conditional Statements
- Random Module
- User Input

## How to Run

python racing_car.py
