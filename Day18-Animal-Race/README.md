# Animal Race Game

## Overview

This is a simple command-line Animal Race game made while practicing Python.

Different animals move at different speeds, and the first animal to reach the finish line wins the race.

## Features

- Multiple animals
- Different movement speeds
- Random movement
- Race progress display
- Automatic winner detection

## Concepts Practiced

- Classes and Objects
- Inheritance
- Polymorphism
- Functions
- Loops
- Conditional Statements
- Random Module
