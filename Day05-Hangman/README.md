# Hangman Game

## Overview

This project is a simple command-line Hangman game built using Python.

The computer randomly selects a word, and the player has to guess it one letter at a time. The game continues until the player guesses the complete word or runs out of attempts.

---

## Features

* Random word selection
* Letter-by-letter guessing
* Tracks guessed letters
* Limited number of attempts
* Displays the correct word when the game ends

---

## Concepts Practiced

* Lists
* Strings
* Loops
* Functions
* User Input
* Conditional Statements
* `random` Module
