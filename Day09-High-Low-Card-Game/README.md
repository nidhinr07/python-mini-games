# High Low Card Game

## Overview

This project is a simple command-line High Low Card Game built using Python.

The player is shown a card and must guess whether the next randomly generated card will be **higher** or **lower**. The game continues until the player chooses to exit, and the final score is displayed.

---

## Features

* Random card generation
* Higher or lower guessing
* Score tracking
* Multiple rounds
* Exit option

---

## Concepts Practiced

* Functions
* Dictionaries
* Loops
* User Input
* Conditional Statements
* Random Module
