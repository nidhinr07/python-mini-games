# Blackjack Game

## Overview

This project is a simple command-line Blackjack game built using Python.

The player gets cards and tries to get a score as close to 21 as possible without going over. The computer also draws cards, and the scores are compared at the end.

## Features

* Player and computer cards
* Score calculation
* Ace handling
* Multiple rounds
* Play again option
* Bust detection

## Concepts Practiced

* Variables
* Lists
* Functions
* Loops
* User Input
* Conditional Statements
* Random Module
