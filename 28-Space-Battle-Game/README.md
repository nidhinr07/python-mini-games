# Space Battle Game

## Overview

This is a simple command-line Space Battle game made while practicing Python.

The player fights an enemy spaceship by attacking or repairing their spaceship.

## Features

- Player vs Enemy
- Random attack damage
- Health system
- Healing option
- Multiple turns
- Exit option
- Win and lose conditions

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Random Module
- Score and Health Tracking

## How to Run

python space_battle.py
