# Dice Roller

## Overview

This project is a simple command-line Dice Roller built using Python.

The program simulates rolling a six-sided dice. The user can roll the dice as many times as they want and exit the game by typing **`exit`**.

---

## Features

* Generates a random number between 1 and 6
* Roll the dice multiple times
* Exit the game anytime
* Simple and beginner-friendly

---

## Concepts Practiced

* Functions
* Loops
* User Input
* `while` Loop
* `break`
* `random` Module
