# Tic Tac Toe

## Overview

This project is a simple two-player Tic Tac Toe game built using Python.

Players take turns placing **X** and **O** on a 3×3 board. The game checks for a winner after every move and ends when a player wins or the board is full.

---

## Features

* Two-player gameplay
* Displays the game board after every move
* Checks for winning combinations
* Detects a draw
* Prevents invalid moves

---

## Concepts Practiced
