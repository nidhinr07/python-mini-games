# Treasure Chest Game

## Overview

This is a simple command-line Treasure Chest game made while practicing Python.

The player chooses between three chests and tries to find gold while avoiding traps.

## Features

- Three treasure chests
- Random chest contents
- Random gold points
- Trap system
- Score tracking
- Exit option

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Dictionaries
- Random Module
- Score Tracking

## How to Run

python treasure_chest.py
