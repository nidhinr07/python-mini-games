# Treasure Hunt Game

## Overview

This project is a simple command-line Treasure Hunt game built using Python.

The treasure is hidden in one of nine positions. The player has three attempts to find it by choosing different positions.

## Features

* Random treasure location
* Limited attempts
* Simple game board
* Position checking
* Play again option
* Exit option

## Concepts Practiced

* Lists
* Functions
* Loops
* User Input
* Conditional Statements
* Random Module
