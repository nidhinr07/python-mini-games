# Fishing Game

## Overview

This is a simple command-line Fishing Game made while practicing Python.

The player has a limited number of casts and tries to catch different types of fish to earn points.

## Features

- Limited number of casts
- Random fishing results
- Different fish with different scores
- Score tracking
- Exit option
- Final score

## Concepts Practiced

- Classes and Objects
- Methods
- Encapsulation
- Functions
- Loops
- Conditional Statements
- Random Module
