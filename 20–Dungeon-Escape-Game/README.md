# Dungeon Escape Game

## Overview

This is a simple command-line Dungeon Escape game made while practicing Python.

The player explores different rooms in a dungeon. Some rooms contain traps, some contain treasure, and one room contains the exit.

The goal is to find the exit while keeping your health above zero.

## Features

- Random rooms
- Health system
- Treasure and score
- Trap damage
- Exit room
- Final score

## Concepts Practiced

- Classes and Objects
- Methods
- Functions
- Lists
- Loops
- Conditional Statements
- Random Module
- User Input
