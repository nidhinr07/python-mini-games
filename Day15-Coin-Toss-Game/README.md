# Coin Toss Game

## Overview

This project is a simple command-line Coin Toss game built using Python.

The player chooses Heads or Tails, and the computer randomly tosses the coin. The score is updated after every round until the player chooses to exit.

## Features

* Heads or Tails choice
* Random coin toss
* Score tracking
* Multiple rounds
* Exit option
* Final result

## Concepts Practiced

* Variables
* User Input
* Conditional Statements
* Loops
* Functions
* Random Module
