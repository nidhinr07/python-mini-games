# Quiz Battle Game

## Overview

This is a simple command-line Quiz Battle game made while practicing Python.

The game asks multiple questions and gives the player a score based on their answers.

## Features

- Multiple questions
- Multiple-choice answers
- Score tracking
- Correct answer display
- Play again option

## Concepts Practiced

- Lists
- Dictionaries
- Functions
- Loops
- User Input
- Conditional Statements
- String Handling
