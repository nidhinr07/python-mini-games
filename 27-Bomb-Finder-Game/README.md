# Bomb Finder Game

## Overview

This is a simple command-line Bomb Finder game made while practicing Python.

A bomb is hidden behind one of nine boxes. The player chooses boxes and tries to find all the safe ones without finding the bomb.

## Features

- Random bomb location
- Nine boxes
- Score system
- Prevents repeated choices
- Exit option
- Win and lose conditions

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Lists
- Random Module

## How to Run

python bomb_finder.py
