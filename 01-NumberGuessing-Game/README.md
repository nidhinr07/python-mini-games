# Number Guessing Game

A simple Python game where the player tries to guess a randomly generated number.

## How to Play

- The computer selects a random number between 1 and 100.
- The player gets 7 attempts to guess the correct number.
- After each guess, the game gives hints.

## Concepts Used

- Variables
- User Input
- Random Module
- While Loop
- If-Else Conditions

## How to Run

python number_guessing_game.py
