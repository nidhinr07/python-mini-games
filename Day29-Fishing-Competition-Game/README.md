# Fishing Competition Game

## Overview

This is a simple command-line Fishing Competition game made while practicing Python.

The player competes against the computer for five rounds. Both try to catch as many fish as possible.

## Features

- Player vs Computer
- Five rounds
- Random fish count
- Score tracking
- Final winner

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Random Module

## How to Run

python fishing_competition.py
