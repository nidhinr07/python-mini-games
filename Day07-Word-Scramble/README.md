# Word Scramble Game

## Overview

This project is a simple command-line Word Scramble game built using Python.

The program randomly selects a word, scrambles its letters, and asks the player to guess the original word. The game continues until the player types **`exit`**.

---

## Features

* Random word selection
* Scrambled words every round
* Score tracking
* Multiple rounds
* Exit option

---

## Concepts Practiced

* Lists
* Strings
* Functions
* Loops
* User Input
* Conditional Statements
* Random Module
