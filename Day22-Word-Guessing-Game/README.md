# Word Guessing Game

## Overview

This is a simple command-line Word Guessing game made while practicing Python.

The computer chooses a random word, and the player tries to guess it one letter at a time.

## Features

- Random word selection
- Letter guessing
- Limited attempts
- Shows guessed letters
- Play again option

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Lists
- Strings
- Random Module

## How to Run

python word_guessing.py
