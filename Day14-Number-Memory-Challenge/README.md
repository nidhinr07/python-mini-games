# Number Memory Challenge

## Overview

This project is a simple command-line memory game built using Python.

The program shows a random number for a few seconds. The player has to remember and enter the number after it disappears.

Each time the player gets the answer correct, the number becomes longer and the level increases.

## Features

* Random number generation
* Increasing difficulty
* Level tracking
* Memory challenge
* Exit option

## Concepts Practiced

* Variables
* Functions
* Loops
* Strings
* User Input
* Conditional Statements
* Random Module
* Time Module
