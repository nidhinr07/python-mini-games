# Monster Battle Game

## Overview

This is a simple command-line battle game made while practicing Python OOP concepts.

The player can choose a Warrior or Mage and fight against a monster. The battle continues until either the player or the monster loses all health.

## Features

- Choose a character
- Attack the monster
- Monster attacks back
- Health tracking
- Random damage
- Exit option

## Concepts Practiced

- Classes and Objects
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Functions
- Loops
- Conditional Statements
- Random Module
