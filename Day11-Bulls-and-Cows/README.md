# Bulls and Cows Game

## Overview

This project is a simple command-line Bulls and Cows game built using Python.

The computer generates a random 4-digit number with unique digits. The player tries to guess the number, and after each guess the program displays the number of **Bulls** and **Cows**.

* **Bull** means the correct digit is in the correct position.
* **Cow** means the correct digit is in the wrong position.

The game continues until the player guesses the correct number or exits.

---

## Features

* Random secret number generation
* Bulls and Cows hints
* Unlimited attempts
* Exit option
* Beginner-friendly code
