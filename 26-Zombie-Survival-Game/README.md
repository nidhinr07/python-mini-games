# Zombie Survival Game

## Overview

This is a simple command-line Zombie Survival game made while practicing Python.

The player tries to survive by searching for food, weapons, and avoiding zombies.

## Features

- Health system
- Food system
- Random events
- Score tracking
- Multiple actions
- Exit option

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Random Module
- Score Tracking

## How to Run

python zombie_survival.py
