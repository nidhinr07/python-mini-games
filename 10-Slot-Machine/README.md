# Slot Machine Game

## Overview

This project is a simple command-line Slot Machine game built using Python.

The player starts with a balance of coins. Each spin costs 10 coins, and the slot machine randomly displays three symbols. Matching symbols reward the player with extra coins.

The game continues until the player chooses to exit or runs out of coins.

---

## Features

* Random slot spins
* Coin balance tracking
* Jackpot and matching rewards
* Multiple rounds
* Exit option

---

## Concepts Practiced

* Functions
* Lists
* Loops
* User Input
* Conditional Statements
* Random Module
