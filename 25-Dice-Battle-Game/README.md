# Dice Battle Game

## Overview

This is a simple command-line Dice Battle game made while practicing Python.

The player and computer roll a dice, and the higher number wins the round.

## Features

- Player vs Computer
- Random dice rolls
- Score tracking
- Multiple rounds
- Exit option
- Final result

## Concepts Practiced

- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- Random Module

## How to Run

python dice_battle.py
