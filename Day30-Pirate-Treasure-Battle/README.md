# Pirate Treasure Battle

## Overview

This is a simple command-line Pirate Treasure Battle game made while practicing Python.

The player fights against a computer pirate while searching for hidden treasure.

## Features

- Player vs Computer
- Attack system
- Treasure searching
- Random events
- Health system
- Score tracking
- Exit option

## Concepts Practiced

- Classes and Objects
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Functions
- Loops
- Conditional Statements
- Lists
- Random Module

## How to Run

python pirate_treasure.py
